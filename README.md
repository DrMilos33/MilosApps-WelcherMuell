# Welcher Müll?

Eigenständige öffentliche MilosApps-Nachschlage-App mit dem App-Key
`waste-guide`.

Ein Gegenstand oder Material wird gesucht. Die App zeigt eine kurze,
quellenbasierte Entsorgungsempfehlung, wichtige Ausnahmen und bei regionalen
Unterschieden einen klaren Hinweis auf den örtlichen Entsorger.

## Feste Grenzen

- kein Konto und keine Nutzerdatenbank;
- keine erfundenen oder pauschalisierten Kommunalregeln;
- eigener DEV-Lifecycle, Production nicht freigegeben;
- keine Shared-Abhängigkeit ohne veröffentlichten Release;
- Portal-DEV bindet nur über dokumentierte Metadaten und URL an.

Siehe [Produktbrief](docs/PRODUCT_BRIEF.md), [QA-Plan](docs/QA_PLAN.md) und
[Erkenntnisse](docs/LEARNINGS.md).
